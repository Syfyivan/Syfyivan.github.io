# Mahjong Tile Assets

The PNG tile images in this directory were cropped and resized from
`raster/tileset2.png` in `tempai-dev/riichi-mahjong-tiles-svg`.

Source: https://github.com/tempai-dev/riichi-mahjong-tiles-svg
Source commit: 18960b1513486c53829bbef5b6ff32ba99aa27ae

The upstream package declares `license: (MIT OR CC-PDDC)`.
This project uses the tile images under the CC-PDDC public-domain option.

`white.png` keeps the same tile base and adds a local green-frame overlay so
the blank dragon is visually distinct from a missing image.
