    Recall Drill

    默写训练

    题 1 / 8

    “客成社测预”分别是什么？

    先回到医院大门，看五块牌子。

    客户属性、成本属性、社会属性、可测性、可预见性。

    最终只背这 8 句

    1. 质量五属性：客成社测预。
    2. SQA：部门独立，工程师深入，小组折中。
    3. 评审为早抓，晚抓代价大。
    4. 质量费用：预评内外。
    5. 测试流程：单测模块，集测接口，系统测整体，验收看用户。
    6. 测试找错，调试改错；测试用例是输入、条件、预期。
    7. 白盒：接数边路错。
    8. 黑盒：等边因判错；上驱下桩别记反。
