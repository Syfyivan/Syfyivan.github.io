<div class="csf-key-note"><strong>用 AI 做项目能点火，但要真入这行，基本功一门都不能少——而且 AI 时代更要学扎实。</strong>这条路线图把科班的硬功夫拆成 6 门零基础也能起步的课：<strong>扎实讲原理 + 自己动手练 + 练判断，绝不让 AI 代写</strong>。配套姊妹课《写给高考生的编程第一课》打完基础后，从这儿继续往深里走。</div>

建议按下面顺序学（也可按需挑）：

<a class="csf-row" href="/courses/csf-python/"><span class="csf-num">1</span><div class="csf-rt"><h4>编程语言入门（Python）（12 讲）</h4><p>从装好环境到独立写出一个命令行小程序，一行一行亲手敲，真正学会用 Python 写代码。</p></div></a>
<a class="csf-row" href="/courses/csf-dsa/"><span class="csf-num">2</span><div class="csf-rt"><h4>数据结构与算法（12 讲）</h4><p>程序的内功——从大 O 直觉到动态规划，全靠自己手写推导加 Python 小练习练出来的那点真本事。</p></div></a>
<a class="csf-row" href="/courses/csf-net/"><span class="csf-num">3</span><div class="csf-rt"><h4>计算机网络（11 讲）</h4><p>跟着一次网页请求，把「从按下回车到页面出现」中间的每一步亲手走一遍。</p></div></a>
<a class="csf-row" href="/courses/csf-os/"><span class="csf-num">4</span><div class="csf-rt"><h4>操作系统（11 讲）</h4><p>从双击图标到程序运行，看懂操作系统这位大管家怎么在幕后调度 CPU、分配内存、管理文件，让你的电脑同时跑得起几十个程序。</p></div></a>
<a class="csf-row" href="/courses/csf-db/"><span class="csf-num">5</span><div class="csf-rt"><h4>数据库（11 讲）</h4><p>从把数据记在哪、怎么不弄丢、怎么查得快出发，用 SQLite 亲手敲 SQL，把认真记住数据这件基本功练扎实。</p></div></a>
<a class="csf-row" href="/courses/csf-arch/"><span class="csf-num">6</span><div class="csf-rt"><h4>计算机组成原理（12 讲）</h4><p>从一个开关到一段能跑的程序，看懂计算机到底怎么把电变成计算。</p></div></a>
