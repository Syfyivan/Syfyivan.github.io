> 承上：上一章阿评把“怎么评、谁来评”全学会了。这一章，老裁判要他明白：比试过关，不是终身有效。

阿评以为发了合格证就完事了。老裁判摇头：“一纸合格证管不了一辈子。选手上了岗，得有人常年盯着。”

他列了几样要盯的。“一是**本事会慢慢退**——世道变了、来的活儿变了，他那套渐渐不灵，分数悄悄往下掉。二是**会出事**——哪天被人下了套、办错了要紧的事，得第一时间知道。三是**会超支**——盘缠用量哪天猛涨，得有人报警，别等月底账单吓一跳。四是**观众的反馈得收回来**——谁满意谁骂街，攒起来，正好变成下一轮的考题。”

“考核场和真世界，”老裁判说，“是一个转圈：上岗、盯着、收反馈、再回炉、再上岗。”

> 所属路径：AI 与 Agent 大寓言课 / 第 08 讲：会验收的裁判 / 08.6 线上监控

## 概念揭晓

老裁判要盯的这几样，是 AI 系统的**线上监控**——把“上线前的评测”延伸到“上线后的持续观测”。

“本事慢慢退、分数往下掉”，是**质量漂移（quality / model drift）**：随着真实世界变化（用户、数据、需求），线上表现悄悄下滑，呼应第二讲 02.4 的分布漂移。

“被下套、办错要紧事”，是**安全事件监控**：及时发现注入、越权、有害输出等安全问题（第九讲专讲）。

“盘缠用量猛涨要报警”，是**预算 / 成本告警**：盯 token、调用量、延迟，异常飙升要能及时告警（呼应第二、三讲的成本意识）。

“观众反馈攒成下一轮考题”，是**反馈闭环（feedback loop）**：把线上真实结果、用户反馈、失败样本收集回来，喂进评测集和下一轮迭代。

## 上线是另一段开始

上线前的评测，是在你准备的题上考；上线后，模型面对的是真实、变化、甚至有人故意捣乱的输入。两者的分布永远对不齐，所以：

- 上线前评测再好，也不能保证上线后一直好。
- 真实世界会持续变化，模型会持续“变差”——不是它退化了，是世界变了。

因此监控不是可选项。一个负责任的 AI 系统，上线那一刻，监控就得同时上线。

## 线上要盯哪几类信号

- **质量信号**：能拿到真实结果时持续算线上指标；拿不到时，用代理信号（真分数拿不到时的“替身”指标，如用户重试率、点踩率、人工介入率）和抽样评测。举个具体例子：一个客服 Agent 上线时抽样准确率 88%，平稳几周；某次大促，用户突然大量问“满减叠不叠优惠券”这类训练时少见的问法，离线评测照样是 88%（题没变），可线上的“转人工率”从 6% 悄悄爬到 19%——**模型没退化，是世界变了，题型漂出了它会的范围**。这正是为什么要盯代理信号：真实准确率往往拿不到即时标注，而转人工率、重试率这类信号能第一时间替你“报警”。
- **安全信号**：异常请求、疑似注入、越权操作、有害输出（第九讲）。
- **成本与性能**：token 用量、调用次数、延迟、错误率——异常要告警、能限流。
- **用户反馈**：显式（点赞点踩、投诉）和隐式（放弃、改写、转人工）。

关键是要能**告警**和**回滚**：发现异常，第一时间通知到人，并能快速退回上一个可用版本。

## 把线上失败变成离线评测

线上监控最大的价值，不只是“发现问题”，而是“喂养评测”：

- 把线上的真实失败样本收集起来，归类（08.4 的失败图鉴）。
- 把这些真实坏例子加进你的评测集和回归集。
- 下次迭代前，先在这套“真实难题”上考——确保老问题不复发、新版本真变好。

这样，评测集会随真实使用不断长大、越来越贴近现实。线上的每一次翻车，都变成了下一版更可靠的养料。

## 评测—监控—迭代的闭环

把整讲收成一个圈：

1. **离线评测**：上线前，在自有评测集上系统化考核（08.1–08.5）。
2. **线上监控**：上线后，持续盯质量、安全、成本、反馈（08.6）。
3. **迭代**：把线上失败收回来，补进评测集，改进系统，再评、再上线。

这个圈一直转，系统才不会随世界变化而退化。它和第二讲 02.6、第十二讲产品化讲的是同一件事的不同侧面——AI 系统是持续运转的循环，不是一次性交付。

## 本讲收束 · 下一讲预告

阿评在第八讲学会了当一个不讲情面的裁判：识破“表演不算考过”（08.1）、考会答话的看哪几样（08.2）、考会办事的看过程与结果（08.3）、给每场录像可回放（08.4）、用 rubric 和模型评委一起打分还要抽检（08.5），最后懂得上岗后要常年盯（08.6）。

收场时阿评问老裁判：“我能挑出本事不行的。可有些选手本事够，却心术不正——被人塞张纸条就乱办事、还偷看不该看的。这种怎么防？”老裁判往城门一指：“那就不是裁判的事了，是守城门的事。”——那是第 09 讲 [会守城的门卫：安全、隐私与治理](/courses/ai-agent-fables/) 的故事。
