## 一、为什么网络这一环要单独讲

号有了、卡有了，很多人还是栽在网络上，原因有三：

- **地区可用性**：部分海外 AI 服务对某些地区不开放或体验受限。
- **延迟与稳定性**：网络不稳，长对话、Agent 长任务、上传下载都很难受。
- **账号风控**：这是最隐蔽的一条——**很多平台的风控会看你的 IP**。IP "不干净"或频繁跳变，可能触发验证、限流，甚至封号。

前两个好理解，重点说第三个：**IP 也是账号安全的一部分。**

## 二、什么是"IP 纯净度"

平台风控会根据 IP 的**类型和信誉**给你打分。常被提到的"IP 纯净度"，大致指这几个维度：

- **住宅 IP（家宽）vs 机房 IP（数据中心）**：家庭宽带的 IP 被看作"真人在用"，信誉高；数据中心 IP 常被自动化、批量注册滥用，信誉低、容易被风控盯上。
- **是否被滥用 / 连坐**：一个 IP 如果被很多人共用、或历史上被拿去做过批量注册、欺诈，它就被"污染"了。你用上这种 IP，会被别人的行为连累。
- **风险评分**：很多公开服务会给 IP 标注"风险分""是否代理/VPN""是否数据中心"等。

一句话：**风控更信任"看起来像真实住宅用户"的 IP，警惕"看起来像机器农场"的 IP。**

## 三、查一查你的 IP 长什么样

在动手注册重要账号前，可以先用公开工具看看自己当前出口 IP 的归属、类型和风险评分（这些都是只读查询，纯信息性）：

- [ipinfo.io](https://ipinfo.io/)
- [ip.sb](https://ip.sb/)
- [ping0.cc](https://ping0.cc/)（会给"IP 类型/风险"评估）
- ipapi.is、ipregistry.co 等

看几件事：**归属地对不对、是不是数据中心 IP、风险分高不高**。心里有数，再决定要不要换个更合适的网络环境。

## 四、一条最重要的原则：地区一致性

把这门手册三篇串起来，你会发现一条贯穿的原则：

> **手机号归属地、IP 归属地、账号注册地区，尽量保持一致。**

- 用[爱沙尼亚号](/2026/06/21/ai-toolbox-01-esim-overseas-number/)注册，就让访问 IP 也落在爱沙尼亚附近；
- 在某地区 App Store 充值订阅，平时使用也别和该地区差太远；
- 号在 A 国、IP 在 B 国、卡在 C 国，这种"三国拼凑"最容易触发风控。

风控的底层逻辑是"这个人看起来是不是一个真实、稳定、自洽的用户"。地区一致、行为稳定，就越像真人，越省心。

## 五、账号与设备隔离的概念

还有一个值得知道的稳妥习惯，是**隔离**：

- **不同账号别混用同一套环境**：一个环境出问题，别牵连到其它账号。
- **重要账号的注册邮箱、设备分开管**：即使某个账号出意外，也能快速重建，不至于一锅端。
- **开启两步验证（Authenticator）和 Passkey**：账号来之不易，别让它轻易丢。

这和[大寓言课第九讲"会守城的门卫"](/courses/ai-agent-fables/)里讲的**隔离、最小化、纵深防御**是同一套思路——把"出一次事"的影响面压到最小。

## 六、几个常见的网络问题

- **收不到验证短信**（接的是 eSIM 号时）：打开"数据漫游"，再开关一次飞行模式重试。
- **总是弹验证码 / 人机校验**：往往是 IP 信誉问题或地区不一致，先查 IP、对齐地区。
- **时好时坏**：网络不稳定会让 Agent 长任务频繁中断，稳定性比峰值速度更重要。

## 七、合规与边界（请认真读）

这一篇刻意只讲**为什么**和**原则**，没有给任何"翻墙""绕过风控""防封号"的操作步骤，原因很简单：

- **跨境网络访问受所在地法律法规约束**，请自行了解并遵守，合规第一。
- **绕过服务商的地区限制、风控与验证，可能违反其服务条款**，后果（包括封号、损失订阅费）自负。
- 本文的定位是帮你**理解网络对账号的影响**，做一个稳定、自洽、合规的使用者，而不是教你对抗任何系统。

把网络理顺的正确姿势，是让自己的使用**真实、稳定、地区自洽**——而不是去钻空子。
