## 一、故事正文

灵枢宗新弟子苏青萝入门第一日，长老没有先教她写代码，也没有先教她软件测试，而是在石壁上写下两个字：**质量**。长老说：「你以后做软件质量保证与测试，第一件事不是急着找缺陷，而是先弄明白什么叫质量。」

青萝心里早有答案。她脱口而出：「质量嘛——功能越多越好、界面越漂亮越好、材料越贵越好。」长老没有反驳，只把她带到山门外的小丹房。丹房里有一炉刚出炉的「清心丹」，色泽温润，入口微甘，装在白玉瓶里极是好看。青萝看了一眼便笃定：「这炉丹药质量一定很高。」长老不语，只说：「今日有三位求丹人要来，你来发药，看看是不是人人都说它好。」

第一位是闭关三日的内门师姐，只求丹药能让她一炷香内心神安定，好继续参悟剑诀。青萝递上清心丹，师姐服下后确实安定，却昏睡了两个时辰，醒来错过了师尊讲法。她摇头：「药性虽纯，却误了我的时辰——我要的是**及时见效**。」

第二位是远道而来的商队掌柜，要给百名伙计备药，只要求药效温和、便宜、便于携带。青萝仍递出白玉瓶清心丹。掌柜看了价格，又看瓶身易碎，叹道：「此丹精巧，可路上颠簸就碎了，又这么贵——我要的是**成本低、好带**。」

第三位是药堂长老，他不是自己服药，而是要把这丹列入宗门常备药。他没有先看丹色，只连问青萝：「药材来源可追溯吗？每一炉药效是否稳定？瓶上有没有用量说明？弟子误服后如何处理？」青萝一句也答不上来。药堂长老合上药匣：「你看到的是外观，我问的是**稳定、可追溯、可管理**——这是要纳入**体系**去管的。」

回到石壁前，长老写下课件原话：**质量是一组固有特性满足要求的程度**。青萝这才懂：同一炉丹药没有变，可三位**客户**各有各的**要求**——师姐要及时有效，掌柜要成本合适、便于携带，药堂长老要稳定可追溯可管理。丹药不会因为看起来珍贵就「质量高」，它必须满足使用者真正的要求。长老最后补一句：「质量不是绝对的，它**相对客户而存在**，而且**由客户判定**。」

## 二、本节术语

本讲学生必须掌握、答题必须原样写出的正式术语：

- 质量、质量的定义（ISO 8492 / ISO 9000 / IEEE 三个定义）
- 组织、过程、产品、服务、客户、体系（与质量相关的概念）
- 固有特性、要求、明示需求、暗示需求
- 质量属性：客户属性、成本属性、社会属性、可测性、可预见性
- 内部客户（职级、职能、工序、流程四种）、外部客户、潜在客户
- 客户与质量的关系（相互依赖、质量由客户判定）
- 四种质量观点：制造者观点、产品观点、用户观点、基于价值的观点
- 质量概念三层次：符合性质量、适用性质量、广义质量
- 质量形成过程：朱兰质量螺旋曲线、ISO9000 质量环
- 质量管理发展五阶段：无知、觉醒、启蒙、懂事、成熟

核心定义先背下来这一句：

> **质量是一组固有特性满足要求的程度。**

## 三、概念正解

### 3.1 与质量相关的六个概念（组织 / 过程 / 产品 / 服务 / 客户 / 体系）

| 概念 | 课件定义 |
| --- | --- |
| **组织** | 职责、权限和相互关系得到安排的一组人员及设施；两个或两个以上个人为实现共同目标组合成的有机整体。 |
| **过程** | 一组将**输入**转化为**输出**的相互关联或相互作用的活动；由输入、实施活动、输出三个环节组成，一般伴随时间先后次序。 |
| **产品** | 过程的结果或过程的中间结果。四种通用类别：**硬件、软件、服务、流程性材料**；按存在形式又分有形和无形。 |
| **服务** | 向客户提供技术支持、帮助和关心等的行为；服务也是一种**无形产品**，是对有形产品的补充。 |
| **客户** | 不仅包括接受产品或服务的组织或个人，还包括**潜在客户**；更广义地说，是公司为实现目标所需的产品和过程影响到的人。 |
| **体系** | 相互关联、作用或依存的一组要素构成的有机整体；有一定组织形式，受规则控制，变化有序，趋于和谐。 |

### 3.2 质量的三个定义（高频考点，三家都要会）

- **1986 年 ISO 8492 定义**：质量是产品或服务所满足**明示或暗示需求**能力的特性和特征的集合。
- **ISO 9000（2000 版）定义**：质量是**一组固有特性满足要求的程度**。（最常考、最该背）
- **IEEE 定义**：质量是系统、部件或过程满足客户或用户**明确需求或期望**的不同程度。

通俗讲：质量不是「越贵越好、越复杂越好、越漂亮越好」，而是产品、服务或过程的固有特性，是否满足客户及相关方的明示需求和暗示需求。

### 3.3 明示需求与暗示需求

- **明示需求**：客户明确说出来的要求。如师姐说「一炷香内心神安定」。
- **暗示需求**：客户没说出口但合理存在、理应满足的要求。如药不能让人误了修炼、运输途中不能碎裂、每一炉药效不能差异巨大。
- 考试常坑：只写「满足客户明确需求」，**漏掉暗示需求**或相关方要求。

### 3.4 质量的五个属性

质量的内涵由一组满足客户及其他相关方所要求的固有特性组成。

| 属性 | 含义 |
| --- | --- |
| **客户属性** | 质量**相对客户而存在**，是质量相对性的体现。 |
| **成本属性** | 也叫质量的经济性；质量越好，带给社会的损失越小。 |
| **社会属性** | 质量很多时候是一种理念、是哲学而不仅是方法，与社会价值观直接相关。 |
| **可测性** | 质量好坏取决于对相应特征的衡量；可测性决定了质量的可控特性。 |
| **可预见性** | 可以预测质量在不同过程中的结果。 |

### 3.5 客户：内部客户、外部客户、潜在客户

- **内部客户**：组织内部的部门和员工；内部某一方向对方提供产品或服务，「对方」就是内部客户。内部客户又分**四种**：**职级客户、职能客户、工序客户、流程客户**。
- **外部客户**：不是组织内部的组成部分，但受本组织活动影响的个人和组织；即传统意义上大家认知的客户。
- **客户的确定**（三组划分）：实际的客户与**潜在的客户**；直接的客户与间接的客户；关键的少数客户与次要的多数客户。
- 一句名言：「每个人都有客户，如果他不知道自己的客户是谁、也不知道客户需要什么，那么他还没有了解自己的工作。」

**客户与质量的关系**：质量相对客户而存在，二者是**相互依赖**的关系——质量服务于客户、因客户存在而存在，且**质量由客户判定**；客户是质量的接受者，可直接观察或感觉到质量的存在。

### 3.6 四种不同的质量观点

| 观点 | 内涵 |
| --- | --- |
| **制造者的观点** | 质量是产品性能和规格要求的**符合度**。 |
| **产品观点** | 质量是联结产品**固有性能**的纽带。 |
| **用户观点** | 质量是产品满足**使用目的**之程度。 |
| **基于价值的观点** | 质量依赖于顾客愿意付给产品**报酬的数量**。 |

### 3.7 质量概念的三个层次

- **第一层次——符合性质量**：能满足国家或行业标准、产品规范的要求，最初的质量观念。
- **第二层次——适用性质量**：让客户满意，不仅满足标准规范，还满足客户的其他要求。
- **第三层次——广义质量**：不仅让客户满意，还要让客户**愉快**——想在客户前面，超出客户的希望。（狭义质量 → 广义质量的发展）

### 3.8 质量形成过程：朱兰螺旋与 ISO9000 质量环

- **朱兰质量螺旋曲线**：把质量看作贯穿全过程、螺旋上升的活动链——市场研究 → 开发 → 设计 → 制定产品规格 → 制定工艺 → 采购 → 工序控制/生产环境建立 → 生产 → 检验测试 → 销售 → 零售批发 → 服务 → 维护支持，再回到市场研究，循环上升达到「适用性（质量）」。强调质量是**全过程、全员、循环改进**的结果。
- **ISO9000 质量环**：产品寿命周期的闭环——营销和市场调研 → 产品设计和开发 → 过程策划和开发 → 采购 → 生产或服务提供 → 验证 → 包装和储存 → 销售和分发 → 安装和投入运行 → 技术支持和服务 → 售后 → 使用寿命结束时的处置或再生利用。强调质量贯穿产品**全生命周期**。

### 3.9 质量管理的发展历程（五个阶段）

按时间从早到晚，五个阶段对应五种管理水平与做法：

| 阶段 | 大致时间 | 标志做法 |
| --- | --- | --- |
| **无知** | 1900 前后 | 手工操作者自己把关 |
| **觉醒** | 1920 前后 | 专职检验员 |
| **启蒙** | 1931 前后 | 过程统计技术 |
| **懂事** | 1960 前后 | 全面质量管理 |
| **成熟** | 2000 前后 | 以顾客为中心 |

## 五、考点卡

- **判断题抓手**：
  - 「质量越高，成本一定越高。」——**不严谨**。质量有成本属性，但高质量不是无约束堆料，而是在要求和约束下满足需求。
  - 「客户只包括购买产品的人。」——**错**。客户包括接受产品/服务的组织或个人，还包括潜在客户及受产品和过程影响的人。
  - 「质量是相对客户而存在的。」——**对**。不同客户要求不同，对同一产品的质量评价可能不同，且质量由客户判定。
  - 「服务不是产品。」——**错**。服务是一种无形产品，是对有形产品的补充。
- **选择题抓手**：
  - 看到「固有特性、满足要求、明示/暗示需求、客户及相关方」→ 联想**质量定义**。
  - 看到「客户属性、成本属性、社会属性、可测性、可预见性」→ 联想**质量五属性**。
  - 看到「符合度 / 固有性能纽带 / 使用目的 / 愿付报酬」→ 分别对应**制造者 / 产品 / 用户 / 价值**四观点。
  - 看到「符合性 / 适用性 / 广义」→ 联想**质量三层次**。
  - 看到「螺旋曲线」→ 朱兰；看到「质量环、全生命周期」→ ISO9000。
- **填空题抓手**：
  - 质量是一组固有特性满足 **要求** 的程度。（ISO 9000）
  - 质量是相对 **客户** 而存在的，且质量由 **客户** 判定。
  - 质量不仅要满足 **明示** 需求，也要满足 **暗示** 需求。
  - 内部客户分为职级、职能、**工序**、**流程** 四种。
  - 质量管理发展五阶段：无知、觉醒、**启蒙**、懂事、**成熟**。
- **简答题答题骨架**（「简述你对质量的理解」）：
  1. 给定义：质量是一组固有特性满足要求的程度。
  2. 要求来源：包括客户及相关方的明示需求和暗示需求。
  3. 相对性：不同客户、不同场景对质量评价不同，质量由客户判定。
  4. 补属性：客户、成本、社会、可测性、可预见性五属性。
  5. 举例收尾：同一软件对普通用户、运维、管理者要求不同。
- **设计题答题骨架**（给一个系统分析其质量要求）：
  1. 写出主要客户和相关方（含内部/外部/潜在）。
  2. 列明示需求。
  3. 推断暗示需求。
  4. 说明这些需求体现了客户属性、成本属性、可测性或可预见性等本章质量属性。
  5. 用四种质量观点或三个质量层次归纳评价角度；不展开后续章节的软件质量模型术语。

## 六、小试炼

**题 1（判断）**：只要软件功能多、界面漂亮，就可以认为软件质量高。
参考答案：**错**。质量取决于固有特性满足要求的程度。功能多、界面漂亮只是部分特性，不满足客户真实需求仍不能算高质量。

**题 2（选择）**：以下哪项最符合 ISO 9000 对质量的定义？
A. 产品价格越高质量越高　B. 产品功能越多质量越高　C. 一组固有特性满足要求的程度　D. 产品外观越精美质量越高
参考答案：**C**。这是 ISO 9000(2000) 的标准表述；A、B、D 都是把表面属性误当质量。

**题 3（填空）**：质量是一组固有特性满足 ______ 的程度；质量是相对 ______ 而存在的。
参考答案：**要求**；**客户**。前者是 ISO 9000 定义关键词，后者是客户属性。

**题 4（简答）**：为什么说质量具有客户属性？
参考答案要点：质量相对客户而存在；客户是质量的接受者；不同客户有不同需求和期望；同一产品在不同场景可能得到不同质量评价；故评价质量必须结合客户及相关方要求，且质量由客户判定。

**题 5（选择）**：「质量是产品满足使用目的之程度」属于哪种质量观点？
A. 制造者观点　B. 产品观点　C. 用户观点　D. 基于价值的观点
参考答案：**C**。强调「使用目的」即用户观点；制造者看符合度，产品看固有性能，价值看愿付报酬。

**题 6（设计）**：某学校要开发一个在线考试系统，请只用本章「质量」框架分析其质量要求。
参考答案示例：
1. 先确定客户：学生、教师、教务管理人员、学校等，注意内部客户、外部客户和潜在客户。
2. 列出明示需求：能出题、组卷、答题、交卷、评分、查询成绩等。
3. 推断暗示需求：考试期间结果应可信，操作过程应能被检查，异常情况应有处理办法。
4. 从客户属性看：不同客户对同一系统的质量判断不同，学生重视能顺利考试，教师重视评分与管理，学校重视管理秩序。
5. 从成本属性看：质量不是无约束堆功能，而是在要求和成本之间形成合理满足。
6. 从可测性/可预见性看：关键要求要能被检查、记录和预测，便于质量控制。
7. 最后可用符合性质量、适用性质量、广义质量说明质量认识的三个层次。

注意：这里故意不展开可靠性、性能、安全性、可维护性等后续章节的软件质量模型术语；本题只考第 1 章框架。

## 七、易错点

- 把**质量**理解成「高级感 / 越贵越好」。正确：质量是固有特性满足要求的程度，相对客户而存在。
- 只看客户**说出口**的需求，漏掉**暗示需求**和相关方要求。
- 把**客户**只当成「买东西的人」，漏掉内部客户、潜在客户、受过程影响的人。
- 把**质量**当成最后检查出来的结果。正确：质量贯穿组织、过程、产品、服务、体系，由朱兰螺旋/ISO9000 质量环可见它是全过程、全生命周期的。
- 混淆**四种观点**与**三个层次**：观点讲「从谁的角度看质量」（制造者/产品/用户/价值），层次讲「质量认识的发展深度」（符合性/适用性/广义）。
- 故事记住了，但答题不写正式术语。正确做法：故事帮理解，答卷必须落到「固有特性、要求、明示/暗示需求、客户属性、成本属性、可测性、可预见性」等课件关键词。
