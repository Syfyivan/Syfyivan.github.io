## 先给总排序

如果没有更强的个人兴趣，我建议这次志愿按下面的优先级组织：

1. **计算机 / 软件 / AI**：最宽口径，就业面广，本科就业和读研都灵活。
2. **电子信息 / 通信 / 微电子 / 集成电路**：长期壁垒高，适合能接受读研的工科路线。
3. **临床 / 口腔 / 麻醉 / 医学影像学**：想当医生才放；接受长学制、规培和高强度。
4. **统计 / 数学 / 数据科学**：适合数学不排斥、未来想保留 AI/金融/考研/考公多条路。
5. **法学**：表达、阅读、抗压强可以放，路径是法考、考研、公务员、律所和企业合规。
6. **自动化 / 电气 / 机器人 / 智能制造**：稳定工科路线，适合国企、电网、制造业、军工院所。
7. **智能医学工程 / 生物医学工程 / 药学**：医工或医药交叉，不是医生，更适合读研后发展。
8. **师范 / 心理 / 农食海洋大气**：有明确兴趣或稳定偏好再放，不做默认主线。

一句话版：**默认还是新工科优先；如果她真的想当医生，医学可以和新工科并列成第二主线；如果还没定方向，统计/数学和法学比普通管理类更值得放。**

提前批单独处理：**只填“录了也愿意去”的学校和专业方向**。这里的“好大学”门槛要比普通批更高：如果只是东大、大工、强 211 这类本来普通批就能争取的学校，不建议为了提前批换成明显不喜欢的弱专业。

## 这篇怎么用

你的 640 分是今年分数，真正用来对照的是 **4435 名**。2025 辽宁物理类里，637 分约 4398 名，636 分约 4544 名，所以可以这样理解：

- **冲**：2025 位次约 3000-4400，高于或贴近 4435，值得放前面，但不能指望稳。
- **贴线 / 主稳**：约 4400-6000，最该密集填的核心区。
- **稳**：约 6000-7500，学校或专业不亏，录取把握明显提高。
- **保**：约 7500-10000，用行业强校、硬专业兜底。
- **最后兜底**：10000 以后，只在城市、省内或稳妥极重要时放。

下面所有内容都是用 2025 辽宁物理类专业投档数据做参照。2026 招生计划、专业备注、学费、校区、单科限制、体检限制可能变化，正式填报前必须回到网报系统、学校章程和《辽宁招生考试之窗》核对。

本科提前批在普通本科批之前录取。提前批录了，后面的 112 个本科批志愿就不会再走；提前批没录，不影响本科批。因此提前批不是“免费抽奖”，而是单独一套只放高意愿选项的志愿池。

## 一、本省 985 先怎么排

这组最该盯紧，因为辽宁本省 985 对本省考生友好，学校层次和工科认可度都强。

- **冲｜大工 软工｜639 / 4039**：比 4435 高约 400 名；如果想要大工+计算机方向，这是最现实的普通专业口。
- **贴线冲｜东大 计科｜637 / 4398**：和 4435 几乎贴线；建议放在东大自动化、AI 前面。
- **主稳｜大工 智能制造｜636 / 4544**：和你的位次同档；大工平台强，新工科属性明确。
- **主稳｜东大 自动化类｜635 / 4735**：东大王牌方向，比很多“名字热”的专业更硬。
- **主稳｜东大 AI / 机器人工程｜635 / 4735**：新工科方向明确，可以放在自动化附近。
- **主稳｜东大 软工特色班｜634 / 4913**：比计科稳，仍是计算机方向。
- **稳｜东大 电子信息类｜632 / 5294**：通信、电子方向，适合放在东大软工后面。
- **稳｜东大 智能制造｜630 / 5677**：承接东大本部工科，不要漏。
- **稳｜东大 计算机类｜629 / 5882**：作为东大计算机方向兜底很合适。
- **条件保｜大工 计算机类中外｜618 / 8439**：校名强、方向好，但学费和培养口径要逐条确认。

大工软工 -> 东大计科 -> 大工智能制造 -> 东大自动化 -> 东大 AI/机器人 -> 东大特色软工 -> 东大电子信息 -> 东大智能制造 -> 东大计算机类。

如果家里能接受中外合作费用，再把大工计算机类中外放到“保底但校名强”的位置；不能接受就不要放。

## 五、医学：想当医生才放，不想当医生别硬填

医学不是“女生稳妥专业”的简单替代品。临床、口腔、麻醉、医学影像学是医生方向，培养周期长、强度高；但如果她真的想当医生，这个分数可以认真放一条医学线。

### 医生方向怎么放

- **冲｜吉大 临床白求恩班｜640 / 3873；639 / 4039**：贴近 4435，能冲。
- **冲｜山东大学 临床五年制｜637 / 4398**：和当前位次几乎贴线。
- **主稳｜首医 儿科学｜636 / 4544**：学校强，儿科专业要确认本人接受。
- **主稳｜中南 临床医学类｜634 / 4913**：985，含临床、口腔、精神医学。
- **主稳｜大工 临床医学｜633 / 5103**：大工临床是新医科路线，学校平台强，但医学资源和传统医科大学不同，要单独了解。
- **稳｜天津医大 临床｜632 / 5294**：医学平台明确。
- **稳｜中国医大 临床 5+3｜631 / 5474**：本省医科强校，5+3 适合医生路线。
- **稳｜哈医大 临床 5+3｜630 / 5677**：东北医学强校。
- **保｜中国医大 口腔｜621 / 7691**：口腔适合想当医生但不想临床夜班太重的人。
- **保｜大连医大 临床 5+3｜617 / 8681**：本省医学保底强项。

### 医学方向的判断

- **能接受 8 年左右培养周期，再把医学放前面。**
- **口腔医学性价比高**：就业体面、夜班少、可开诊所，但分数也高。
- **不要因为“女生”就填护理**：640 / 4435 去护理通常不划算，除非本人明确喜欢护理。
- **医学影像学和医学影像技术不是一回事**：前者偏医生，后者偏技师，填前要看学位和执业路径。

## 六、医工交叉 / 药学：适合作为工程和医学之间的备选

### 值得看的方向

- **山大 智能医学工程｜638 / 4214**：AI+医疗，偏工程，不是医生。

## 十、本科提前批：好大学可以接受弱专业时怎么用

你的想法是对的：如果大学特别好，提前批里有些相对冷门或特殊专业可以看。但这里要把“大学特别好”和“大学比较好”分开。**很好的大学 + 可接受的弱专业**可以讨论；**比较好的大学 + 不喜欢的弱专业**不值得。

判断标准不是“学校越好越无脑填”，而是三句话：

- 录了以后，能不能接受它替代后面的普通本科批志愿；
- 专业、体检、政审、协议就业、服役或工作性质有没有硬约束；
- 这个平台是不是明显强于普通本科批能拿到的“大工 / 东大 / 吉大 / 强 211 新工科”。

按这个口径，提前批不再承担“多一个东大机会”的任务。普通本科批已经能冲东大计科、自动化、AI、软工、电子信息，大工软工和智能制造也在主线里；如果提前批只是把这些学校换成材料、资源、外语、建筑、经管、中外合作等不想读的方向，就不填。

2026 辽宁普通类本科提前批分 **A 段**和 **B 段**：

- **A 段**：军队院校、飞行技术、北京电子科技、中国消防救援、中央司法警官、综合评价等；设置 2 个有序院校志愿，每个院校 4 个专业志愿和专业服从。
- **B 段**：公安院校公安类专业、国家公费师范、航海类等艰苦专业、小语种、重点马克思主义学院马克思主义理论等；设置 60 个“专业+学校”平行志愿。
- **综合评价**：安排在 A 段。符合条件或已获资格的考生，通常要把综评院校放在本科提前批 A 段第一顺序志愿。

### 对 640 / 4435 最值得看的提前批

- **第一类｜真正高一档平台**：香港中文 `654`、港中深 `650`、香港科技大学（广州）`645`、香港城市 `629`、清华 `683` 这类，学校平台明显高于普通批主线。640 分重点看港城、港科广/港中深冲刺；清华基本不现实。港校和合作办学要单独确认费用、培养地点、专业、语言环境和家庭接受度。
- **第一类补充｜南科大 / 上科大 / 昆山杜克 / 北外等综评**：如果已经有资格，或者 2026 网报系统和学校章程明确允许填报，可以单独看；如果没有前置报名、校测或资格，不要当成现在才开始准备的补报机会。
- **只核验不盲报｜北航提前批｜2025：598**：北航是明显高一档学校，但提前批低分可能对应飞行技术或其他特殊培养，不是普通北航冷门专业。只有在 2026 招生计划里看清专业、身体条件、培养方式和就业约束后，才能讨论。
- **特殊强平台｜北京电子科技｜2025：631 / 658**：它不靠综合排名取胜，而是信息安全、电子政务、党政机关就业导向特殊。640 分可以看，但政审、体检、专业代码、就业去向必须逐条核；如果只想普通互联网/新工科就业，就不填。
- **特殊强平台｜外交 / 国关 / 海关**：外交学院 `618`，国际关系 `599 / 604`，上海海关 `629 / 650`。这些不是“弱专业捡名校”，而是涉外、国安、海关、政法、考公路径。只有愿意走这些职业方向才放。
- **条件冲｜军校 / 军医 / 国防信息类**：国防科大 `543 / 633`，海军军医 `590 / 629`，空军军医 `570 / 631`，网络空间部队信息工程 `567 / 632`，信息支援部队工程 `612 / 630`。优点是平台强、纪律性强、就业路径清楚；代价是政审、军检、训练、服役和专业性别计划。女生名额通常少，必须看 2026 招生计划中的院校代码、性别、体检标准和专业说明。
- **只按职业意愿看｜部属公费师范**：东师 `629`，陕师 `618`，华中师 `614`，西南大学 `606`。如果她愿意当老师，这是专业本身成立；如果不想被任教协议和就业地域约束，就不要把它当“比较好大学弱专业”的替代。
- **只按职业意愿看｜公安 / 司法 / 消防**：中国刑警 `608 / 632`，中国人民警察 `560 / 625`，公安大 `595 / 587`，中央司法 `566 / 604`，消防救援 `550`。适合愿意走执法、安全、司法、消防体系的人；政审、面试、体检、体能测评是前置条件。
- **不主推｜东大综评**：2026 东大辽宁综评计划 340 人，不占普通统招计划；填在普通类本科提前批 A 段。但按你现在的新口径，东大综评不适合放在提前批主推位。原因很简单：东大是好学校，但不是“为了弱专业也值得提前锁死”的更高一档学校；普通批已经能冲东大计科、自动化、AI、软工、电子信息。除非综评专业池里有她本来就愿意读的具体专业，否则不填。
- **不作为当前提前批机会｜大工**：目前能明确查到的是大工强基计划，不是像东大这样“辽宁 A 段填报即报名”的综评。强基报名和确认都有前置时间，如果之前没有完成，不要把它当成现在还能补报的提前批入口；大工仍按普通本科批里的软工、智能制造、数学、临床等来排。
- **不主推｜大连海事航海类｜2025：587**：学校不错、分数低，但它不是“很好的大学弱专业”，而是航海技术、轮机工程、船舶电子电气等特殊职业方向。2026 辽宁志愿须知也专门提醒女生慎重报考航海类。除非本人真接受海上专业，否则不填。

### 我会怎么放

- **A 段只放 1-2 个真正愿意去的学校**：优先是港校/顶尖综评/北航这类高一档平台，或北京电子科技、国防科大、军医、消防、司法这类特殊强平台。顺序志愿很看第一志愿，专业服从也要慎重。
- **B 段宁缺毋滥**：公费师范、公安、航海、小语种、马院等是 60 个“专业+学校”平行志愿，但仍然在本科批之前录取。没有明确职业意愿，就少填甚至不填。
- **好大学差专业的底线**：只接受“平台明显高一档 + 专业相对冷但生活方式可接受”。不接受“比较好大学 + 明显不想读专业”。材料、数学、外语、马理论、公费师范、军警司法、航海，每一个背后的生活方式都不同。
- **如果拿不准，宁愿少填**：4435 名普通本科批已经能做出不错的新工科组合，提前批只是加机会，不要让提前批反过来破坏主线。

## 十二、哪些选项要单独判断

### 中外合作

中外合作可以降低分数门槛，比如大工计算机类中外、北邮电子信息中外、西电数据科学中外、东秦计科中外等。但必须逐条确认：

- 学费是不是能接受；
- 上课地点和培养模式；
- 是否影响转专业、保研、出国；
- 毕业证、学位证、外方学位规则；
- 课程语言和数学/英语压力。

如果这些没确认，先不要把中外合作放太靠前。

### 校区 / 分校

东秦、大工盘锦、哈工大威海/深圳、厦大马来西亚等，都要看清校区。它们不是不能报，但不能当成本部普通专业来理解。

### 大类招生

“计算机类”“电子信息类”“自动化类”“工科试验班”通常要进校后分流。填报前要问清楚：

- 大类里是否真的包含你想要的专业；
- 分流规则按绩点还是志愿；
- 进热门方向需要排到前多少；
- 分不到热门方向时会去哪些专业。

### 专业名很热但实质偏窄

“智能制造”“机器人”“数据科学”“人工智能”这些名字看起来都很新，但实际培养差异很大。强校可以报，普通学校要看课程和学院归属。尤其是智能制造，如果课程仍偏传统机械，就不要放在计算机、电子信息、自动化前面。

## 最终建议

如果没有更强的城市、费用、读研偏好，我建议主线这样定：

1. **第一主线**：计算机、软件、AI、电子信息、通信、微电子、集成电路。
2. **第二主线**：临床、口腔、麻醉、医学影像学；前提是本人想当医生。
3. **第三主线**：统计、数学、数据科学、法学。
4. **第四主线**：自动化、电气、机器人、智能制造。
5. **提前批支线**：只看高一档平台或特殊强平台，例如港校/顶尖综评、北航特殊类型、北京电子科技、国防科大/军医/国防信息类、外交国关海关等；东大综评、大连海事航海类、公费师范、公安司法消防只有在专业或职业路径本身也愿意时才填。
6. **补充主线**：智能医学工程、生物医学工程、药学、师范心理、农食海洋。

一句话版：**不要为了“985”牺牲到不喜欢的冷门专业，也不要为了“计算机”把学校层次降太多。4435 名最好的打法，是“本省 985 + 强 211 新工科”做主线；如果她本人愿意当医生，就把临床/口腔单独拉成第二主线；提前批只作为“录了也满意”的额外机会，再用法学、统计、医工交叉补足选择面。**
