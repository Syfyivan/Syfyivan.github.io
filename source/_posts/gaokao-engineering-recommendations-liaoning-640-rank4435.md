## 先给结论

**第一优先级：计算机 / 软件 / 人工智能。**
如果目标是就业面宽、后续转方向灵活，优先选 **计算机科学与技术、软件工程、计算机类、人工智能**。在 4435 名这个位置，最关键的是：**大连理工软件、东北大学计科、东北大学自动化/AI/机器人、吉林大学计科/AI、北京科技大学计算机、南京理工/苏州大学/西南交大计算机**。

**第二优先级：电子信息 / 通信 / 集成电路 / 微电子。**
如果能接受读研，电子信息和集成电路性价比很高。重点看 **南京航空航天微电子/电子信息、北京交通电子信息、华北电力通信/电子、吉林大学集成电路/通信、东北大学电子信息、南京理工电子信息、南京邮电/杭州电子科技电子信息**。

**第三优先级：自动化 / 电气 / 机器人工程 / 智能制造。**
如果想要“新工科 + 稳定 + 国企/制造业/电网可能性”，自动化、电气、机器人、智能制造值得放。重点看 **大工智能制造、东大自动化/机器人/智能制造、华北电力自动化、西南交大电气、上海电力电气、东北电力/三峡电气**。

**不建议只按学校最低分填。** 辽宁是“专业+院校”模式，4435 名要按**专业投档位次**排，不要看到某校校线低就以为热门工科也稳。

## 这篇怎么用

你的 640 分是今年分数，真正用来对照的是 **4435 名**。2025 辽宁物理类里，637 分约 4398 名，636 分约 4544 名，所以这篇把 2025 专业投档位次大致分成：

| 梯度 | 2025 位次参考 | 怎么理解 |
|---|---:|---|
| **冲** | 3000–4400 | 高于或贴近 4435，值得放前面，但不能指望稳 |
| **贴线 / 主稳** | 4400–6000 | 最该密集填的核心区 |
| **稳** | 6000–7500 | 学校或专业不亏，录取把握明显提高 |
| **保** | 7500–10000 | 用行业强校、硬专业兜底 |
| **最后兜底** | 10000 以后 | 只在城市/省内/稳妥极重要时放 |

> 说明：下面所有 2025 投档分和位次，来自已整理的辽宁招考办官方投档表附录。2026 招生计划、专业备注、学费、校区、单科限制、体检限制可能变化，正式填报前必须回到网报系统、学校章程和《辽宁招生考试之窗》核对。

### 2.2 计算机方向怎么取舍

1. **能选“计科/计算机类/软件工程”，优先这些宽口径。**
   本科阶段别太早把路走窄，计算机类和软件工程后续转 AI、数据、安全、后端、测试开发、产品技术岗都比较灵活。

2. **AI 专业要看学校平台。**
   东大、南航、吉大、北科、华北电力这类可以报；如果只是普通学校把专业名改成 AI，不如选更强学校的计算机类/软件工程。

3. **行业强双非可以做保底，不要拿来压过 985/强 211。**
   杭电、南邮、重邮、西安邮电是行业认可高的学校，但在你这个位次，前面仍应先放 985/211 的硬专业。

### 3.2 电子信息方向怎么取舍

1. **想长期上限：微电子 / 集成电路可以优先。**
   但要接受“读研更稳”这个前提。本科直接就业也可以，但好岗位更偏硕士。

2. **想就业面更宽：电子信息类 / 通信工程更稳。**
   通信、电子、嵌入式、硬件测试、算法、运营商、设备商、军工院所都能走。

3. **电子信息不要只看专业名，还要看学校行业资源。**
   西电、南邮、杭电、重邮虽然学校层次不同，但在通信/电子行业里有自己的认可度。

### 4.2 这组专业怎么取舍

1. **自动化是工科“万金油”，比很多人想象中更值得报。**
   东北大学自动化尤其值得重点放，学校王牌和专业方向匹配。

2. **电气适合想稳定、进国企/电网的人。**
   如果未来更想要稳定，华北电力、上海电力、东北电力、三峡大学、长沙理工这些电力相关学校可以放得比普通 211 更靠前。

3. **机器人工程 / 智能制造要看学校平台。**
   大工、东大、南航、吉大、北科这些平台可以报；普通学校的“智能制造”可能实际仍偏传统机械。

4. **纯机械类谨慎放。**
   除非学校平台很强、专业有机器人/智能制造方向，或者你本人明确喜欢汽车、装备、航空航天，否则放在计算机、电子信息、自动化、电气之后。

| 5 | **自动化** | 东大等学校王牌方向，通用工科能力强 |

| 7 | **机器人工程 / 智能制造** | 新工科属性强，但要看学校平台，避免被普通机械包装 |
| 8 | **数据科学 / 信息与计算科学 / 大数据管理** | 可以作为补充，但别把它们当成纯计算机替代 |

### 5.2 不同目标下的排序

**目标是高薪和就业面**：
计科/软件 → 电子信息/通信 → AI → 集成电路 → 自动化 → 电气 → 机器人/智能制造。

**目标是稳定和国企**：
电气 → 自动化 → 电子信息/通信 → 计科/软件 → 集成电路 → 智能制造。

**目标是读研后冲上限**：
集成电路/微电子 → 计科/AI → 电子信息 → 自动化/机器人 → 数学/信息与计算。

**目标是不想读太久，尽量本科就业**：
计科/软件 → 电气 → 电子信息/通信 → 自动化 → 机器人/智能制造。集成电路如果不读研，要慎重。

## 七、哪些选项要单独判断

### 1. 中外合作

中外合作可以降低分数门槛，比如大工计算机类中外、北邮电子信息中外、西电数据科学中外、东秦计科中外等。但必须逐条确认：

- 学费是不是能接受；
- 上课地点和培养模式；
- 是否影响转专业、保研、出国；
- 毕业证、学位证、外方学位规则；
- 课程语言和数学/英语压力。

如果这些没确认，先不要把中外合作放太靠前。

### 2. 校区 / 分校

东北大学秦皇岛分校、大连理工盘锦校区、哈工大威海/深圳、厦大马来西亚等，都要看清校区。它们不是不能报，但不能当成本部普通专业来理解。

### 3. 大类招生

“计算机类”“电子信息类”“自动化类”“工科试验班”通常要进校后分流。填报前要问清楚：

- 大类里是否真的包含你想要的专业；
- 分流规则按绩点还是志愿；
- 进热门方向需要排到前多少；
- 分不到热门方向时会去哪些专业。

### 4. 专业名很热但实质偏窄

“智能制造”“机器人”“数据科学”“人工智能”这些名字看起来都很新，但实际培养差异很大。强校可以报，普通学校要看课程和学院归属。尤其是智能制造，如果课程仍偏传统机械，就不要放在计算机、电子信息、自动化前面。

## 八、最终建议：这次填报的主线

如果没有更强的城市、费用、读研偏好，我建议主线就按下面来：

1. **前排冲**：西电/南航/北交/湖大的计算机、电子信息、微电子，以及大工软件、东大计科。
2. **核心主稳**：大工智能制造，东大自动化/AI/机器人/软工/电子信息/计算机类，吉大计科/AI/集成电路/通信，北科计算机/自动化。
3. **稳妥扩展**：南理工、苏大、西南交大、中国海洋、华东理工的计算机/电子信息/自动化。
4. **强专业保底**：杭电、南邮、哈工程、合工大、河海、武汉理工、东北电力、三峡、重邮、西邮。
5. **最后兜底**：辽宁大学和本省工科院校的硬专业。

一句话版：**不要为了“985”牺牲到不喜欢的冷门专业，也不要为了“计算机”把学校层次降太多。4435 名最好的打法，是“本省 985 + 强 211 新工科”做主线，用杭电/南邮/东北电力这种行业强校做硬专业保底。**
