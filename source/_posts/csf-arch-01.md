你每天都在用十进制数数:1、2、3……到 9 之后,凑不出新符号了,就往左边进一位,变成 10。这个"逢十进一"你太熟了,熟到从来没想过:**凭什么是十?**

答案有点扫兴——因为人有十根手指。换句话说,十进制只是个**习惯**,不是宇宙真理。机器没有手指,它有的是电路。于是它选了另一套习惯:**逢二进一**。这一讲,我们就把这套习惯彻底搞明白,顺便让你能用纸笔在十进制和二进制之间来回换。

## 🛠 跟我做

### 先想清楚:进位制是什么 <span class="csf-b csf-core">必读</span>

我们先拆开一个你以为很简单的数:十进制的 `253`。

它其实是这么算出来的:

```
253 = 2×100 + 5×10 + 3×1
    = 2×10² + 5×10¹ + 3×10⁰
```

看出来了吗?每一位上的数字,要乘以一个**权重**,而权重是 10 的若干次方:个位是 10⁰(也就是 1),十位是 10¹,百位是 10²……越往左,权重越大。这个"10"就是**基数**,也就是"逢十进一"里的那个十。

<div class="csf-why">为什么是次方?因为每往左挪一位,就意味着前面那一位已经"装满了"一整轮(满 10),要用更大的单位来记。就像 9 个鸡蛋还能放进一个十格的蛋托,第 10 个来了,蛋托满了,你就得换一句话说"一托零个",这个"一托"就是进位。</div>

现在把基数从 10 换成 2,规则一模一样,只是**每位只能填 0 或 1**(因为逢二就进位,2 这个符号根本不会出现),权重也变成 2 的次方。

来看二进制的 `1101`:

```
1101(二进制) = 1×2³ + 1×2² + 0×2¹ + 1×2⁰
            = 1×8  + 1×4  + 0×2  + 1×1
            = 8 + 4 + 0 + 1
            = 13(十进制)
```

<div class="csf-note"><b>关键一句话:</b> 二进制的每一位,从右往左,权重依次是 1、2、4、8、16、32、64、128……每位翻一倍。把"是 1 的那些位的权重"加起来,就是它对应的十进制数。这一句记牢,二进制转十进制你就会了一半。</div>

### 动手练一:把 0–16 逐个写成二进制,找规律 <span class="csf-b csf-key">重点</span>

这是这一讲最重要的练习。**请拿纸,自己一个一个写**,别往下翻看答案。方法很简单:从右往左,看这个数里"装得下"哪些权重(1、2、4、8、16)。

比如写 13:13 里有 8(剩 5),有 4(剩 1),没有 2,有 1 → 所以是 `1101`。

<div class="csf-note"><b>先猜后做:</b> 在动笔前,先猜一件事——从 0 数到 16,二进制的"位数"(也就是有几个 1 和 0)会在哪几个数字上"变长"?把你的猜测写在纸边上,写完对照下面的表看准不准。</div>

写完了再看答案对照:

```
十进制  二进制        十进制  二进制
  0      0              9      1001
  1      1             10      1010
  2     10             11      1011
  3     11             12      1100
  4    100             13      1101
  5    101             14      1110
  6    110             15      1111
  7    111             16     10000
  8   1000
```

发现规律了吗?

- **每次进位都发生在"刚好凑满一个新的 2 的次方"时**:1→2(变成两位)、3→4(变成三位)、7→8(变成四位)、15→16(变成五位)。这些临界点都是 2 的次方。
- 最右边那一位(个位)在 0、1、0、1 地反复横跳——它每个数都变。这就是"逢二进一"最直接的样子。
- `1111` 是 15,而 `10000` 是 16。注意:**n 个 1 排在一起,等于 2ⁿ 减 1**。四个 1 是 15(也就是 16−1),这个结论后面讲数据范围时还会见到。

### 动手练二:把你的年龄和出生月份转成二进制 <span class="csf-b csf-core">必读</span>

上面是从小数字找规律,现在练一个稍大的数。**十进制转二进制**有个稳的办法叫**除二取余,倒着读**。我们用 25 演示(你换成自己的年龄):

```
25 ÷ 2 = 12 ... 余 1   ↑ 最后读
12 ÷ 2 =  6 ... 余 0   |
 6 ÷ 2 =  3 ... 余 0   |
 3 ÷ 2 =  1 ... 余 1   |
 1 ÷ 2 =  0 ... 余 1   ↓ 最先读
```

把余数**从下往上**读出来:`11001`。

验证一下(用上面那招权重相加):16+8+0+0+1 = 25。对上了!

<div class="csf-why">为什么余数要倒着读?因为你第一次除 2 得到的余数,是这个数"是奇数还是偶数",它对应的是**最低位(个位,权重 1)**;越往后除,得到的是越高位的信息。所以最先算出来的余数放最右边,最后算出来的放最左边。写反了就全错——这正是下面"翻车现场"要重点说的。</div>

现在轮到你:把你的**年龄**和**出生月份**用除二取余各算一遍,写在纸上。算完先别急着信,我们下一步用 Python 验。

### 动手练三:用 Python 验算(注意是验算) <span class="csf-b csf-key">重点</span>

Python 自带一个把十进制转二进制的函数 `bin()`。我们用它来**检查你刚才手算对不对**。

<div class="csf-note"><b>这里务必自己来:</b> 转换的过程(除二取余)一定要你先用纸笔算出结果,再用 `bin()` 核对。如果你跳过手算、直接让工具给答案,这一讲就白学了——你练的是"理解进制",不是"会调函数"。AI 和 Python 在这儿只当你的判分老师,不当你的代笔。</div>

打开终端(上一讲我们装好了 Python),输入 `python3` 再按回车。屏幕上会冒出一个能直接打字、打一行算一行的对话窗口,这个窗口叫**交互环境**——你打一句,它就立刻回你一句结果,不用先写文件、再运行。

进交互环境后,你会看到每行最前面跳出三个尖括号 `>>>`。先说清楚下面这段代码怎么看,免得照着打报错:

- 每行开头的 `>>>` 是 **Python 自己显示的提示符**,意思是"该你输入了"。它不用你敲,你只敲它后面的内容(比如 `bin(25)`),然后按回车。
- 敲完回车,下一行那个带单引号的东西(比如 `'0b11001'`),就是 Python **返回给你的结果**,那行也不用你打,是它自动显示的。
- 某些行后面有个 `#` 加一句中文,`#` 后面的文字叫**注释**,只是写给人看的提醒,Python 会自动忽略它。你打不打这句中文,都不影响结果。

```python
>>> bin(25)
'0b11001'
>>> bin(12)      # 换成你的出生月份试试
'0b1100'
```

输出里的 `0b` 是个前缀,意思是"后面这串是二进制"(b = binary),真正的数字是 `0b` 后面的部分。所以 `bin(25)` 告诉你 25 就是 `11001`——和你纸上算的一样吗?

如果不一样,**别改 Python,去检查你的纸**:多半是某一步余数读反了,或者某个权重加错了。把错的地方找出来,比一次就对更有价值。

### 动手练四:一个字节能表示几个不同的值? <span class="csf-b csf-core">必读</span>

到这里你已经会数二进制了,我们引出今天的第二个主角:**位和字节**。

- **位(bit)**:二进制里的一个 0 或 1,就是一"位"。它是信息的最小单位,英文 bit,简写小写 `b`。
- **字节(byte)**:**8 个位**捆在一起,叫一"字节"。英文 byte,简写大写 `B`。

为什么是 8 个一捆?历史和工程上的折中,你现在只需记住"1 字节 = 8 位"这个换算。

<div class="csf-note"><b>先猜后做:</b> 一个字节有 8 位,每位能是 0 或 1。那么这 8 位组合起来,一共能表示**多少种**不同的值?先在纸上写下你的猜测,再往下看。</div>

想清楚这个,要靠一个简单的乘法。1 位有 2 种可能(0 或 1)。2 位呢?第一位 2 种,第二位 2 种,组合起来 `2×2 = 4` 种(00、01、10、11)。每多一位,可能性就**翻一倍**:

```
1 位 → 2 种
2 位 → 2×2 = 4 种
3 位 → 2×2×2 = 8 种
...
8 位 → 2⁸ = 256 种
```

所以**一个字节能表示 256 个不同的值**。如果用它表示数字,通常是 0 到 255(注意:是 0 到 255,不是 1 到 256,因为 0 也算一个值)。还记得"n 个 1 等于 2ⁿ−1"吗?八个 1(`11111111`)正好是 255,这就是一个字节能装下的最大数。

<details class="csf-fold"><summary>为什么平时说"8 位机""32 位""64 位"?<span class="csf-b csf-skim">细究 · 可跳读</span></summary>
你听过 32 位、64 位的电脑或系统。这里的"位"和我们说的 bit 是同一个概念,指的是 CPU 一次能处理的二进制位数。64 位 CPU 一次能搬动 64 个 0/1。位数越多,一次能表示的数越大、能直接管理的内存也越多——这也是为什么老的 32 位系统最多只能用约 4GB 内存(2³² 个地址)。这些后面讲 CPU 和内存时会展开,现在知道"位"是个贯穿始终的基本单位就够了。
</details>

### 1KB 到底是多少字节? <span class="csf-b csf-key">重点</span>

最后澄清一个几乎人人踩过的坑。日常生活里,K 是一千、M 是一百万,因为我们用十进制。但计算机用二进制,它喜欢的"整数"是 2 的次方。最接近 1000 的 2 的次方是 `2¹⁰ = 1024`。于是在传统约定里:

```
1 KB = 1024 字节(Byte)
1 MB = 1024 KB
1 GB = 1024 MB
```

所以严格说,1KB 是 **1024 字节**,不是 1000。这就是为什么你买个标 256GB 的硬盘,电脑里显示的容量却"缩水"了一点——厂商常按 1000 算容量,系统常按 1024 算,两边对不上,差出来的就是这个零头。

<div class="csf-note"><b>别再混了:</b> bit(b,位)和 byte(B,字节)是两回事,差 8 倍。网速常用 bit 说(比如 "100 Mbps" 是每秒一亿个 bit),文件大小常用 byte 说(比如 "100 MB")。所以 100 Mbps 的宽带,实际下载速度大约是 100÷8 ≈ 12.5 MB/s——而不是 100 MB/s。被这个坑过的人,海了去了。</div>

## 🔧 翻车现场

<div class="csf-note"><b>翻车一:高位低位写反。</b> 除二取余之后,把余数<b>正着</b>读了。记住口诀:<b>余数倒着读,从下往上</b>。最先算出的余数是最低位(放最右),最后算出的放最左。验算方法:用权重相加法反向核对一次,对不上就是读反了。</div>

<div class="csf-note"><b>翻车二:忘了"逢二进一",写出了 2。</b> 二进制每位只能是 0 或 1,绝不会出现 2。一旦你笔下冒出个 2,说明该进位却没进。比如 1+1,不是 2,而是 `10`(逢二进一,本位归零,向左进一)。</div>

<div class="csf-note"><b>翻车三:把"位数"当成"数值大小"。</b> 二进制 <code>10000</code> 看着比 <code>1111</code> 长、像是更大,确实它是 16 比 15 大;但别养成"看长短猜大小"的习惯,要靠权重相加算。位数(有几个 bit)和它表示的数值是两件事——4 个 bit 最多表示 15,不是 4。</div>

<div class="csf-note"><b>翻车四:1KB 当 1000 字节、bit 当 byte。</b> 1KB = 1024 字节;b 是位、B 是字节,差 8 倍。算网速、估文件大小时尤其要分清,不然能差出十万八千里。</div>

## 📦 复制带走

<div class="csf-card"><b>这一讲的四块硬骨头:</b><br>1. <b>进位制</b>:每位的值 = 数字 × 基数的次方。十进制基数是 10,二进制基数是 2,规则完全一样,只是逢几进一不同。<br>2. <b>二进制互转</b>:二进制→十进制用"权重(1、2、4、8…)相加";十进制→二进制用"除二取余,余数倒着读"。<br>3. <b>位与字节</b>:1 个 bit 是一个 0/1;8 个 bit = 1 个 byte;n 位能表示 2ⁿ 个值,所以 1 字节 = 256 个值(0–255)。<br>4. <b>单位换算</b>:1KB = 1024 字节(不是 1000);bit(b)和 byte(B)差 8 倍,算网速别搞混。</div>

下一讲,我们要解决一个二进制目前还表示不了的东西:**负数**。再顺便认识一个程序员天天用、专门"给人看"的简写——**十六进制**。到时你会明白计算机是怎么用一个巧妙的把戏(补码),让"减法"变成"加法"的。咱们第02讲见。
