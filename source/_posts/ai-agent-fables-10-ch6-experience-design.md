> 承上：上一章阿行知道了照界面办事会栽哪些跟头。这一章，老向导问他一个更软、却更要紧的问题：人凭什么放心把事交给你这样一个旅人？

阿行答“因为我办得成啊”。老向导摇头：“办得成只是一半。人把事交给你，心里是不踏实的——你走到哪了他不知道、你要是走偏了他拦不住、你办错了他没法补。这些不解决，再能干也没人敢用。”

他给阿行立了几条“让人放心”的规矩。“**让人看得见你走到哪**——别闷头跑，随时让主人知道进度。**缰绳随时能接回去**——主人想停、想自己来，你立刻让位。**走错了好纠正**——给人改的余地，别一错到底。**什么能自己定、什么必须回来问，划清楚**——小事你做主，大事一定回禀。”

## 概念揭晓

老向导这几条“让人放心”，是 AI（尤其是能动手的 Agent）的**体验设计**——把前面所有技术能力，包装成人愿意、敢于使用的样子。

“让人看得见你走到哪”，是**可见的进度（transparency / progress）**：让用户随时知道 Agent 在做什么、做到哪一步、为什么这么做，而不是一个闷头跑的黑箱。

“缰绳随时能接回去”，是**接管权（human control / takeover）**：用户能随时暂停、介入、接手，主动权始终在人手里。

“走错了好纠正”，是**可纠错（error recovery）**：给用户撤销、修改、回退的余地，别让一次错误造成不可挽回的后果（呼应回滚）。

“什么能自己定、什么必须回来问”，是**信任边界（trust boundary）**：明确划分 Agent 可自主的范围和必须人确认的范围，按风险来定。

## 能干不等于可用

前面九讲让 Agent 越来越能干。但“能干”和“人敢用、爱用”之间，隔着体验这道坎：

- 看不见它在干嘛 → 不放心。
- 拦不住它走偏 → 不敢放手。
- 错了没法补 → 一次翻车就弃用。

很多技术上很强的 AI 产品没人用，不是因为不够强，而是因为没让人感到“可控、可信、可补救”。体验设计，就是把强大的能力，变成让人安心的产品——这是技术能力落地的最后一公里。

## 可见进度：别做黑箱

人对“看不见的自动化”天然不安。让 Agent 透明，能极大提升信任：

- 实时显示它当前在做什么、计划下一步做什么——比如明明白白写出“正在第 3/5 步：填写收货地址”，而不是转个圈让人干等，猜它到底卡住了还是在跑。
- 对关键决策给出理由（呼应第九讲的可解释）。
- 长任务给阶段性反馈，别让人对着空白等待。

透明不只是好看，它让用户能及早发现“它理解错了”，在小错变大错前介入。

## 接管与纠错：人始终在方向盘上

第七讲 07.5 说过“人对结果负责”。落到体验上，就是：

- **随时可暂停 / 接管**：用户一句话就能让它停下、自己来。
- **可撤销 / 可回退**：操作能撤销，状态能回到之前（第九讲回滚）。
- **可纠偏**：发现它走偏，能纠正方向再继续，而不是推倒重来。

让人“始终握着方向盘、随时能踩刹车”，是放手让 Agent 干活的前提。自动化的程度，应该和“人能多容易夺回控制”成正比。

## 信任边界：按风险授予自主权

不是所有事都该让 Agent 自主，也不是所有事都要人盯着。关键是按**风险**划一条线（贯穿第五、七、九讲）：

- **低风险、可逆**：让它自主做，别拿琐事烦人（读、查、起草）。
- **高风险、不可逆**：必须人确认（动钱、删除、对外发布）。
- 边界要**清晰、可调**：让用户知道它能自己做到哪，并能按自己的信任程度调整。

好的信任边界，让用户既享受自动化的省心，又保留对重要决定的掌控。给多大自主权，本质是“你有多信它在这件事上不会闯祸”。

## 本讲收束 · 下一讲预告

阿行在第十讲从一个观察者，长成了能独当一面、又让人放心的旅人：学会用眼睛看（10.1）、用耳朵听（10.2）、把见闻翻查（10.3）、自己动手办事（10.4）、认得照界面办事的坑（10.5），最后懂得怎样让人放心把事交给他（10.6）。
