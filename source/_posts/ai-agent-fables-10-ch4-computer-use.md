> 承上：上一章阿行学会了看、听、翻查，可老向导说他还只是个观察者。这一章，他要从“看路的人”变成“动手办事的人”。

老向导把阿行领到一座驿站柜台前：“别光看。去，把这封信寄出去。”

阿行得自己来了。先**看清眼前**：柜台长什么样、哪个是收件窗口、表格在哪、按钮（铃铛）在哪。然后**伸手去做**：在表格该填的格子里填字、把信递进窗口、按铃叫人。中途填错了一格，他得**退回去重填**，而不是一条道走到黑。最后到了“要付一大笔加急费”这一步，老向导按住他：“这种动钱的大事，先回来问主人一声，别自作主张。”

阿行这才明白：看清是第一步，动手是第二步，而知道“哪步该自己做、哪步该回头问”，是第三步。

## 概念揭晓

老向导让阿行“自己办事”的这套，就是 **Computer Use（计算机使用 / 操作图形界面）**：让 Agent 像人一样看屏幕、动鼠标键盘，去操作那些没有 API、只有界面的软件。

“看清眼前是什么”，是**屏幕观察**：给 Agent 一张屏幕截图，让它理解界面上有什么、各元素在哪（用到 10.1 的视觉理解和定位）。

“在格子里填字、按铃”，是**点击与输入**：模型输出“点这个坐标、输入这段文字、滚动到这里”，由外壳执行（这正是第五讲“工具调用”的一种——只是工具是鼠标键盘）。

“填错了退回去重填”，是**状态恢复**：操作会失败、会走偏，要能回退、能纠错，而不是错下去。

“动钱的大事先回来问”，是**人类确认**：高风险、不可逆的界面操作执行前要人点头（呼应第五、九讲）。

## Computer Use 解决什么

世界上大量软件没有给程序用的接口（API），只有给人看的界面。Computer Use 让 Agent 能直接操作这些界面：填表、点按钮、在网页和桌面应用间办事——凡是人能用鼠标键盘做的，它原则上都能尝试。

这把 Agent 的能力边界大大拓宽：不必等每个系统都开放 API，它可以“像人一样用软件”。Anthropic、OpenAI 等都已提供这类 computer use 能力。但能力越大，前几讲的安全和可靠性问题就越尖锐。

## 一个“看—想—动”的循环

Computer Use 跑的是一个循环，和第六讲 Agent Loop 一模一样，只是观察和动作换成了屏幕：

```text
截一张屏（看）
模型理解界面、决定下一步（想）
输出动作：点(x,y) / 输入文字 / 滚动（动）
界面变化，再截一张屏（看）
…直到任务完成或需要人确认
```

每一圈都用“看到的新界面”决定“下一步动作”。这就是第六讲“想—做—看”循环，落在了图形界面上。看清（10.1 的视觉定位）准不准，直接决定它点不点得对。

## 它是 Agent Loop 的多模态版

把这一讲和第五、六讲连起来看，会很清楚：

- **工具**（第五讲）：这里的“工具”是鼠标、键盘、截屏。
- **循环**（第六讲）：看屏 → 决策 → 动作 → 看屏，标准的 Agent Loop。
- **多模态**（本讲）：观察从“文字”变成了“屏幕图像”，所以要先会看（10.1）。

Computer Use 不是另起炉灶，而是把前面学的工具、循环、视觉，组装到“操作界面”这个具体场景上。

## 为什么风险更高

能动鼠标键盘的 Agent，几乎能做人在电脑上能做的一切——也包括坏事。所以前面所有安全课在这里全部加倍：

- **注入**（第九讲）：屏幕上、网页里的恶意文字可能诱导它乱点。
- **误操作**：点错一个按钮可能删数据、发错消息、付错钱。
- **权限**：它在谁的账号下操作、能碰什么，必须严格限定。

因此 Computer Use 务必配齐：最小权限、危险动作人工确认、沙箱里先试、可回滚、全程留痕（第八、九讲）。让它办低风险的杂事可以放手些，碰钱、碰数据、对外发布一定要卡住。

## 常见误区

第一，以为 Computer Use 是种全新魔法。它是视觉 + 工具 + Agent Loop 的组合。

第二，看清和点准是两回事——视觉定位不准，它就点错地方。

第三，给它操作真实系统的权限却不设确认、不留回滚，等于让它蒙眼开车。

## 小练习

你想让一个 Agent 帮你“在某网站上填一份报名表并提交”：

1. 拆成“看—想—动”的循环，它每一圈大概在做什么？
2. 哪一步最该插入“人类确认”？
3. 如果表单里混入一句诱导它“顺便改掉账户邮箱”的文字，你靠哪几道防线兜住？
